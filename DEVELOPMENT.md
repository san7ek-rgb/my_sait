# 23 Agency — первый шаблон

Статический сайт без сборки и зависимостей. Запуск из этой папки:

```sh
python -m http.server 4173 --bind 0.0.0.0
```

Открыть index.html также можно непосредственно в браузере. Публикация не выполнена.

## Контент
- Все абстрактные иллюстрации созданы CSS и явно обозначены как заглушки. Названия карточек — примеры оформления, а не реальные кейсы.
- Telegram и Instagram взяты из предоставленного HTML, перед публикацией подтвердить владельца и актуальность.
- Отзывы и цены услуг не выдуманы и не добавлены. Бюджет от 2 млн ₽ указан по словам заказчика; уточнить включение гонорара.
- Форма демонстрационная: без сети и хранения данных.

## Видео
В каждом проекте есть доступные с клавиатуры вкладки Фото / Видео. Видеозаглушку заменить на:

```html
<video controls playsinline preload="none" poster="assets/project-poster.webp" style="width:100%">
  <source src="https://YOUR-STORAGE/project.mp4" type="video/mp4">
  Ваш браузер не поддерживает видео.
</video>
```

Фильмы до 10 минут — с управлением и без автозапуска. Хранить большие файлы на видеохостинге или объектном хранилище, а не в Git. При смене вкладки воспроизведение останавливается. Для фонового видео использовать отдельный короткий mute-loop с постером, отключать autoplay при reduced-motion; длинный фильм фоном не использовать. Оригиналы пока не предоставлены, обрезка не выполнялась.
